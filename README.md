# ARIA VITA™ — Precision Air. Perfect Comfort.

Official website for **ARIA VITA™**, manufacturer and supplier of engineered HVAC air distribution products for commercial, industrial, and residential projects.

Distributed Pan-India by **Ecosta Systems**, Bangalore.

---

## 🌟 Key Features & Offerings

- **Engineered Air Distribution Portfolio:**
  - **Constant Airflow Regulators (CAR):** Self-balancing mechanical airflow controllers operating between 50–250 Pa without electrical actuators.
  - **Fire Retardant Flexible Ducts:** Multi-layer fire-safe aluminum ducting tested to BS 476 and UL 181 safety standards.
  - **Plastic Disc Valves:** Aerodynamic supply and exhaust disc valves with adjustable center cones.
  - **Flexible Duct Connectors:** Vibration-isolation fabric connectors (Neoprene / Canvas / Silicon).
  - **Acoustic Flexible Ducts:** Thermal & acoustic attenuation ducting lined with fiberglass insulation.
  - **Air Curtains:** Commercial and industrial environmental barriers with high-velocity centrifugal blowers.
- **Interactive Airflow Assistant:** Sizing and CFM simulation tool for MEP consultants and project engineers.
- **Direct WhatsApp Project Desk:** Form submission seamlessly formats B2B project inquiries into structured WhatsApp messages directed to **+91 93420 50097** for instant response.
- **Floating WhatsApp Assistance:** Direct chat connectivity for quick technical support.
- **Verified Technical Documentation:** Technical data sheets, airflow performance curves, fire test certificates, and installation guides.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js 18+** installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/BHUVV07/AIRA-VITA.git
cd AIRA-VITA

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.

### Production Build

```bash
npm run build
npm run start
```
